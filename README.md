### URP Batched Immediate Line Renderer Experiment

Explorational project. Unity's standard tools for rendering lines are cumbersome: they create thousands and thousands of objects that you have to manage manually. So I decided to explore how hard it will be to create something that is similar to SFML, DirectX and other imperative frameworks / libraries / standards.

**Goals**
- Understand how low level rendering works in Unity URP
- Try developing an infrastructure for immediate rendering
- Learn how to render different shapes procedurally
- Explore where is the line between customization, ease of use and performance
- Explore how to allow a programmer to use a stack of transformation matrices
- Explore how to create Unity packages
